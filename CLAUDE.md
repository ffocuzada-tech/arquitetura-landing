# CLAUDE.md — Estúdio Vazio

## Projeto
- Site: landing page de arquitetura — empresa fictícia "Estúdio Vazio", parte de um portfólio.
- Stack: Next.js (App Router, TypeScript, Tailwind CSS, pasta `src/`). Animações com GSAP + ScrollTrigger. Deploy na Vercel.
- Idioma: textos, commits, PRs e documentação em português.
- Nomes de arquivos, componentes e variáveis em português, sem acentos (ex.: `Servicos.tsx`, `listaDeProjetos`). Exceção: nomes reservados do Next.js ficam como são (`page.tsx`, `layout.tsx`, `route.ts`).

## Antes de qualquer tarefa, leia
1. `docs/regras.md` — regras obrigatórias (gerais + específicas deste site)
2. `docs/handoff.md` — estado atual e próximo passo
3. `docs/spec.md` — o que este site é e quais seções tem
4. `docs/decisoes.md` — antes de alterar algo que já foi decidido
5. `AGENTS.md` — esta versão do Next.js (16) pode ser diferente do que você conhece:
   antes de escrever código do Next.js, consulte a documentação em `node_modules/next/dist/docs/`.

## Comandos
- `npm run dev` — servidor local (http://localhost:3000)
- `npm run build` — obrigatório sem erros antes de abrir PR
- `npm run lint` — verificação de código

## Skills deste projeto
- `ui-ux-pro-max` — escolher estilo, paleta e fontes adequados ao nicho
- `frontend-design` — direção estética antes de criar qualquer parte visual
- `webapp-testing` — testar no navegador (celular e desktop) antes do PR

> Neste site, paleta, fontes e layout já estão aprovados no `docs/spec.md`.
> As skills servem para executar bem essas decisões, nunca para trocá-las.
